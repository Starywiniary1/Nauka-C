# Embedded C Learning

Repository containing exercises and small projects created while learning C
with a focus on embedded systems.

## Topics

- Integer types
- Conditions
- Loops
- Functions
- Arrays
- Pointers
- Bitwise operations
- Memory
- Make / CMake
- Embedded-oriented C

## Environment

Exercises are initially written and tested using OnlineGDB.
Later exercises will also be compiled locally using GCC.

## Goal

Build solid C fundamentals before moving deeper into STM32,
RTOS and embedded systems development.
